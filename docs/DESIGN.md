# 《？！珠珠！？》— 命运回廊 · 弹珠试炼

手机端横屏（Landscape）弹珠肉鸽游戏，Godot 4.6.3，虚拟分辨率 1280×720（stretch=canvas_items / aspect=keep，两侧留黑边兼容 20:9 手机）。

## 一、世界观与叙事（来自《游戏世界观及基础设定》）

每个人出生时都有一颗**命运琉璃珠**，代表其一生的命运。当琉璃珠出现裂痕，持有者会被拉入**命运回廊**——一座超脱现世、无限堆叠的巨型弹珠神殿。

回廊中，巨大的弹珠台就是命运本身：立柱是命运中的相遇与磨砺，槽位是结果，虚空大坑是彻底的失败。

- 试炼者把自己的命运琉璃珠发射出去，撞在哪里、掉进哪个洞，就会触发不同的命运。
- 每次进入，弹珠台的布局都会重新随机生成。
- 掉进最底下的虚空大坑，这一轮挑战失败——人不会死，但会被赶出回廊，只能带回一部分碎片资源。
- 回廊里有**守命者**，是命运产生的守护者，会在台上移动，撞偏你的弹珠，不让你改变命运。

叙事表达：全程以“你 vs 命运”的口吻；每关开场抽一张**命运事件**牌，结算用“命运碎片”作为跨局成长货币，体现肉鸽（Roguelike）气质。

## 二、核心玩法（来自《基础策划案》）

Pachinko / Peggle 式物理博弈：

1. **标题界面**：显示最高分、命运碎片总数、开始试炼按钮。点击“开始试炼”进入第 1 关。
2. **商店阶段（每关开始）**：玩家有金币，可购买装备 / 增益卡（弹珠台⑥区关闭按钮 → 启程）。商店 3 件随机货品。购买后点击“启程”进入发射阶段。同时展示本关的**命运事件**与关卡 buff。
3. **发射阶段**：
   - 系统发放 5 枚弹珠（普通珠基础分 5；进阶珠基础分 10）。
   - 玩家在左下发射区**按住蓄力**（蓄力条 0→1，约 1.05 秒蓄满），松手发射；按压时间决定力度。
   - 弹珠从发射区以弧线飞入立柱阵，与立柱自由碰撞后落入底部 6 个槽位之一结算分数。
   - **守命者**在台面上左右巡游，撞到弹珠会将其弹开。
   - 得分公式：`单球得分 = floor((弹珠基础分 + 黄色立柱加成) × 槽位倍率 × 关卡得分倍率)`。
   - 每球结算后刷新分数、剩余弹珠；剩余弹珠全部用完后：
     - 达到目标分数 → **过关**：+5 金币，剩余弹珠进入弹珠库（仅展示），进入下一关商店。
     - 未达目标 → **本局结束**（失败），进入结算。
4. **三关通关** → 胜利结算。
5. **结算界面**：显示本局总分、获得命运碎片、是否刷新最高分；按钮「再来一局」/「返回标题」。
6. **存档**：最高分、累计命运碎片、游玩局数写入 `user://fate_save.json`，重开游戏保留。

## 三、关卡与数值

| 关卡 | 名称 | 目标分 | 关卡 buff |
|---|---|---|---|
| 1 | 裂纹初现 | 25 | 最终得分 ×0.8 |
| 2 | 因果倒错 | 38 | 弹珠基础分 ×1.2 |
| 3 | 无柱之渊 | 45 | 普通立柱全部消失（只剩黄色/绿色） |

（目标分在策划案 25/40/60 基础上按实测手感微调，命运事件还会再 ±5。）

- 初始金币 9，每关发放 5 枚弹珠，过关奖励 5 金币。
- 立柱：6 列 × 7 行 = 42 个；权重 普通 55 / 黄色 30 / 绿色 15，向下取整后用普通柱补位。
  - 普通（灰）：仅反弹。
  - 黄色：每撞击一次，本球基础分 +1（命运事件“因果共鸣”时 +2）。
  - 绿色：相邻（横/竖/斜）绿色立柱彼此连接，弹珠经过连接线会被再次反弹（视觉上以绿色辉光连线表示）。
- 槽位倍率（自左向右）：1.5 | 1 | 0（虚空裂隙）| 1 | 1.5 | 3，占比 0.20/0.15/0.20/0.15/0.20/0.10；槽位区横贯台面全宽 48–1232（不再有两侧虚空缝）。
- 掉入 0 倍率「虚空裂隙」的球不得分；弹珠若从台面越界或超时，同样视为被回廊吞没（0 分）。
- 发射：蓄力 600–1250 px/s，力度决定落点——低力度落左侧，满力度飞向右侧 ×3 槽方向。

## 四、肉鸽元素

- **随机布局**：每关随机生成立柱类型与轻微位置抖动。
- **随机商店**：每关 3 件随机货品。
- **命运事件**：每关开始随机抽取，改变本关规则（+球、+金币、黄柱加成、目标分变化、额外碎片）。
- **局内积累**：金币 → 买装备/卡，滚雪球。
- **跨局遗产**：命运碎片永久累积（结算获得），最高分持久化；失败也保留碎片 → 可继续挑战。

## 六、音频

- BGM：自制命运风格（五声音阶 + 钟磬 + 低音鼓 + 弦乐 pad），菜单/战斗/商店 3 首循环曲，另含胜利/失败短曲。
- SFX：发射、撞柱（普通/黄/绿）、入槽、虚空、金币、购买、点击、守命者、裂痕、胜负。

## 七、操作与适配

- 全触屏。竖屏锁定为横屏（landscape）。
- 蓄力：按住发射区任意位置（左下圆盘）→ 松手发射；同时支持鼠标按住（桌面测试）。

## 十、v1.2 变更（基础策划案(1) + 实机布局 + 局外行囊）

1. **立柱**：6×7 **错落**布局（奇数行横移半列距、±3px 抖动）；5 种立柱权重 普通55/黄30/绿15/黑5/白10。
   - 黑柱：每撞一次该球最终得分 -1（最低 0）。
   - 白柱：每撞一次按 `0.20 + 0.10×该柱本关已撞次数` 概率 +1 金币，计数跨球累计/每关重置。
   - 绿柱：相邻绿柱之间生成真实线段碰撞体，弹珠经过连线会被再次反弹。
2. **随机落入框**：每关随机生成 6 个框的倍率（0~5）与奖励（无/金币+2/再射一球），槽位直接显示。
3. **两阶段进入**：PREP（上半屏购买道具 + 下半屏查看牌组）→ PLAY（正式发射，不再购买）。
4. **卡牌**：强力卡（力度+30%）、分裂卡（撞首柱后分裂 3 颗）、质量卡（低反弹/免疫粘性/撞落黏住的球）、缩小卡（体积0.8/速度1.2）；拖到 ③ 弹珠灯使用，灯变红显示卡名。
5. **装备**：反射器（反弹增强）、粘性器（黏住约 0.9s）；拖到立柱生效。
6. **蓄力轨迹预判**：⑥ 区域显示虚线轨迹与落点；弹珠进入台面后 ⑥ 缺口关闭（Gate），防止回弹。
7. **局外行囊（跨局公共变量）**：一局结束最多带出 3 珠 + 2 卡进入行囊（持久化）；走廊「行囊」面板可查看并勾选（弹珠≤3、卡牌≤2）带入下一局，开局进入弹珠库/待用卡牌。

## 十一、v1.3 变更（像素风 + 8bit + 双倍注 + 引导 + 物理修复）

1. **物理修复**：去掉超时默认虚空清零；卡球（速度<35px/s 持续 1.2s）冲量救援，连续 4 次后传送到台面中央继续落下；只有 y>760 出屏判虚空。闸门只在轨道内无球时关闭，防止夹球。
2. **力度回弹**：蓄力 0→100%→0 三角波来回摆动（单程约 1.05s），松手取当前值；力度条/百分比/轨迹预判实时跟随。
3. **双倍注**：买完道具点开始 → 对话框选择「双倍押注 / 稳妥开局」。双倍：得分×2、金币×2、黑柱惩罚×2、失败碎片减半。
4. **新手引导**：首次进入正式游玩显示像素引导（高亮 ⑦/⑤/③、小手动画、TUTORIAL_TEXT_1~3），只显示一次。
5. **卡牌详情**：⑦ 待使用道具短按弹详情；长按拖拽不变。
6. **像素风**：全部美术改为低分辨率像素绘制 + NEAREST 放大；UI 面板方角硬边框；gameplay 的 `_draw` 用 px.gd 像素工具绘制（4px 对齐矩形/阶梯圆/阶梯弧、粒子方块）。
7. **8bit 音乐**：BGM/SFX 全部重制为 chiptune（方波/三角波/噪声鼓/琶音/滑音），路径与接口不变。
8. **改名**：游戏名改为「！？珠珠？！」（主菜单/窗口/APK 应用名）。
9. **加宽立柱**：`PEG_AREA=552×424`、`PEG_RADIUS=11`，6×7 错落不变；守命者下移到 y=590 / r=18 避免与底行立柱重叠。
