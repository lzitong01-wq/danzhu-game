## 一、游戏流程

```
主菜单「开始试炼」
  → 2D 像素走廊：虚拟摇杆左右移动；顶部「行囊」查看局外弹珠/卡牌
  → 走到当前房间门 → 进入房间
  → 【准备阶段】上半屏购物、下半屏查看牌组
      → 点「开始试炼」→ 弹出「命运双倍注？」对话框（双倍押注 / 稳妥开局）
  → 【正式游玩】不再购物；首次进入有拖动道具的新手指引
      按住右下弹簧蓄力（力度条来回摆动、⑥ 显示虚线轨迹预判）→ 松手发射
      → 沿右侧轨道上行 → 顶部导流斜面 → ⑥ 缺口关闭 → 错落立柱阵（5 种立柱）
      → 落入底部 6 个随机框结算
  → 达标立即过关（+5 金币，剩余弹珠入库）→ 回走廊，下一扇门解锁
  → 3 间全通：胜利结算；5 颗弹珠用完未达标：失败结算（重试本关/返回标题）
  → 一局结束：部分弹珠/卡牌进入「行囊」（跨局公共变量），可勾选带入下一局
```

## 二、v1.3 重点改动（对应 9 条需求）

1. **修复右侧卡球 / 不再超时清零**：弹珠卡住（速度 <35px/s 持续 1.2s）会被冲量救援；连续卡住 4 次后传送到台面中央继续落下；只有真正掉出屏幕（y>760）才判 0 分。闸门只在轨道内无球时关闭，避免夹球。
2. **新手引导**：首次进入正式游玩时弹出像素引导——高亮 ⑦道具库、⑤立柱、③弹珠灯，小手动画演示「长按卡牌/装备 → 拖到立柱或弹珠灯 → 松开生效」，点「知道了」关闭，只显示一次。
3. **8bit 音乐**：全部 5 首 BGM + 13 个音效重制为芯片音乐（方波/三角波/噪声鼓/琶音/滑音/位深量化），时长与无缝循环保持不变（BGM 合计 5.5MB）。
4. **卡牌详情**：⑦「待使用」道具/卡牌**短按**弹出详情（图标/名称/类别/描述/价格），点空白或 × 关闭；长按仍是拖拽。
5. **整体像素风**：主菜单/走廊/台面/立柱/弹珠/门/图标/结算/行囊/引导全部改为像素美术；UI 面板方角硬边框、无阴影，贴图 NEAREST 放大。
6. **双倍注对话框**：买完道具点「开始试炼」时弹出「命运双倍注？」——得分×2、金币×2、黑柱惩罚×2、失败碎片减半；选「双倍押注」或「稳妥开局」。HUD 底部会提示当前双倍状态。
7. **游戏名改为「！？珠珠？！」**：主菜单标题、窗口标题、APK 应用名、版本信息全部同步。
8. **发射力度可回弹**：按住弹簧后力度按 0→100%→0 三角波来回摆动（单程约 1.05 秒），松手取当前力度发射；力度条百分比与轨迹预判实时跟随。
9. **调宽立柱间隔**：立柱区由 528×384 扩大到 552×424、立柱半径 14→11，横向/纵向间距更宽松，同时保持 6×7 错落排布。

## 三、核心玩法（延续 v1.2）

- **错落立柱**：6 列 × 7 行，奇数行横移半列距；5 种立柱：普通（仅反弹）、黄色（撞一次该球基础分 +1）、绿色（相邻绿柱间有真实碰撞连线，撞线再反弹）、黑色（每撞一次该球最终得分 -1）、白色（每撞一次按 20%+10%×已撞次数概率 +1 金币）。
- **随机落入框**：每关 6 个框的倍率（0/1/1.5/2/3/5）与奖励（无/金币+2/再射一球）全部随机。
- **卡牌**（拖到 ③ 弹珠灯，灯变红+卡名）：强力卡（力度+30%）、分裂卡（撞首柱分裂 3 颗）、质量卡（低反弹/免疫粘性/撞落黏珠）、缩小卡（体积×0.8/速度×1.2）。
- **装备**（拖到立柱）：反射器（反弹增强）、粘性器（黏住约 0.9s）。
- **弹珠**：普通珠基础分 5、进阶珠 10（3 颗普通珠合成）；双倍注下得分 ×2。
- **局外行囊**：一局结束最多带出 3 珠 + 2 卡；走廊「行囊」面板可勾选带入（弹珠≤3、卡牌≤2）。

## 五、操作

|---|---|
| 走廊摇杆拖动 / A·D / ←·→ | 移动，走到门边进入房间 |
