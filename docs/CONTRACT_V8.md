## 2. 手游化（全局要求）

- 删除所有键盘交互与桌面提示：走廊不再响应 W/A/D/方向键/ESC（Android 返回键仍可用）；所有文字提示不得出现「按 W」「A/D」「←→」「ESC」「鼠标」等 PC 词汇。
- 交互全部触屏：点击/长按/拖动；交互键为屏幕按钮。
- 主菜单/设置/商店等已有按钮保持触屏操作。

## 3. 回廊 UI（gameplay-dev）

1. **顶部 UI 全部删除**：移除 Lv/第 X/10 间/命核/命运碎片/最高分等整条顶部信息。
2. 只保留：
   - **左上角「← 返回」按钮** → 保存后回主菜单；
   - **右上角「行囊」按钮**（像素图标/文字皆可，建议 `assets/art/bag_icon.png` 或弹珠图标）→ 打开 `character_panel.tscn`（个人信息/行囊）。
3. 底部只保留必要操作提示（触屏语义，如「摇杆移动」「点击交互」），不得出现键盘提示。
4. **交互键**：当玩家靠近当前关 NPC（<交互半径）或门前时，在屏幕**底部偏右**显示圆形/方形「交互」按钮（触屏）；点击后按场景触发对话或「进入试炼」。交互按钮为手游式，不依赖键盘。

## 4. NPC 对话 UI（按 P1，gameplay-dev）

P1 布局：左侧一个**椭圆/圆形角色放大图**，右侧一个**圆角文案框**；交互按钮在**界面中间偏右**。

- 站到镜像 NPC（NPC 面朝玩家）前，点「交互」按钮 → 弹出对话层：
  - 左：椭圆裁切的角色放大图（用 `player_portrait.png` 或 `player_idle.png` 放大，椭圆 mask；可加淡蓝紫法球微光）；
  - 右：圆角文本框，逐字打字机显示 `GameState.get_story_line()`（`STORY_TYPE_SPEED`）；打字中点击文本框 → 立即显示全文；
  - 经文播完后，点击文本框 → 在**界面中间偏右**出现「进入试炼」按钮；
  - 点击「进入试炼」→ `Audio.play_sfx("door")` → 商店（PREP）；NPC 淡出消失 + `mark_npc_seen`；期间玩家移动冻结。
- 若玩家绕过 NPC 直接到关卡门前 → 门前/界面中间偏右弹出「进入试炼」按钮（同样触屏点击）→ 商店。
- 对话层可点击空白处不关闭（防止误触）；仅通过「进入试炼」继续。

## 5. 回廊远景背景（ui-dev 出图 / gameplay 集成）

按用户描述生成 1280×720 背景（像素/低分辨率 NEAREST 亦可）：
- 无尽长廊向纵深延伸：琉璃与暗石交织，透视柱列/拱券渐远，两侧嵌无数黯淡命运琉璃珠（微光点）；
- 画面中部偏上：一颗明亮琉璃珠缓慢旋转，淡蓝+淡紫交织微光（可用多帧序列/代码旋转+辉光叠加）；
- 右侧偏下：模糊高大守命者，只有上半身清晰、下半身渐隐，轮廓被幽光勾勒，静立走廊尽头；
- 整体暗紫/暗棕灰，琉璃微光点缀，压抑中藏希望。
交付：`assets/art/corridor_bg_v2.png`（或分层 `corridor_bg_far/mid.png` + `guardian_silhouette.png` + `orb_glow.png`）；gameplay 负责集成、视差滚动/角色/门的位置适配（门可继续存在，作为长廊中的门）。
